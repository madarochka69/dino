# 📜 KOD — построчный разбор `dino.py`

Этот документ объясняет, что делает каждая часть `dino.py` — тренера NEAT для
Chrome Dino. Номера строк соответствуют текущей версии на **789 строк**
(после сжатия). Код здесь не меняется: только объяснение.

`dino.py` делится на три слоя:

1. **NEAT** — геномы, виды, скрещивание, мутации, фитнес.
2. **Браузеры** — Playwright, страницы, реальные игры, watchdog.
3. **Память** — чекпоинты, лучший геном, история поколений.

## 36–49. Фитнес и защита

| Строки | Что происходит |
|---|---|
| 36–41 | комментарий: почему чистый счёт портит политику и откуда цифры 1800 с / 5280 |
| 42 | `FITNESS_MODE = "ducking-v1"` — версия фитнеса; по ней проверяется совместимость лучшего генома |
| 43 | +2.0 за каждый кадр полезного приседа |
| 44 | −0.1 за кадр бесполезного приседа |
| 45 | −0.5 за кадр прыжка в момент, когда надо приседать |
| 46 | −0.05 за кадр бесполезного прыжка |
| 47 | +50 за каждого птеродактиля, пройденного в приседе |
| 48 | `STALL_SECONDS = 8` — если 8 с нет новых кадров, считаем зависанием |
| 49 | `EVALUATE_TIMEOUT = 8` — максимум на один вызов JS из Python |

Формула фитнеса (строка 315):

```text
fitness = score
        + 2.0  × полезные кадры приседа
        − 0.1  × бесполезные кадры приседа
        − 0.5  × кадры прыжка, когда надо приседать
        − 0.05 × бесполезные кадры прыжка
        + 50   × птеродактили, пройденные в приседе
```

Счёт остаётся основой, бонусы только направляют эволюцию.

## 🧭 Как проходит одно поколение

1. `train` берёт текущую популяцию (или создаёт новую).
2. `evaluate_population` кладёт все геномы в очередь.
3. Каждый `Worker` берёт геном, сериализует сеть и запускает игру.
4. `game_agent.js` каждый кадр считает сеть и двигает динозавра.
5. Python раз в 0.25 с читает `snapshot`; по крашу или таймауту забирает результат.
6. `shaped_fitness` превращает результат в число.
7. NEAT выбирает лучших, скрещивает и мутирует.
8. `speciate` распределяет потомков по видам.
9. `save_checkpoint`, `save_best` и `save_history` фиксируют прогресс.
